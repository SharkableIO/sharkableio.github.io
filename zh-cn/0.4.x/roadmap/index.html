版本：0.4.x

路线图

核心原则：功能通过约定自动发现或配置激活。用户永远不需要改变 ISharkEndpoint 编码模式，不需要实现新接口，不需要在业务代码中调用框架 API。

v0.4.0 — 2026-06-28 ✅​

  • 废弃 [SharkEndpoint] / [SharkMethod] / SharkHttpMethod 及相关反射基础设施 — 迁移到 ISharkEndpoint
  • 启动配置自检 — ConfigurationValidator 在 AddShark() 时校验 JWT、多租户配置
  • 优雅关闭 — K8s 友好的 SIGTERM 处理：/healthz → 503，排空请求，然后关闭
  • 审计日志批量/异步写入 — Channel 缓冲 + 后台刷新（AsyncWrite、BatchSize、FlushInterval）
  • 幂等性分布式存储 — IIdempotencyStore 可通过 TryAddSingleton 或 IdempotencyStoreFactory 替换
  • 限流分布式存储 — IDistributedRateLimitStore + SharkRateLimiterMiddleware，默认 MemoryRateLimitStore，RateLimitStoreFactory
  • Sharkable.Cache.Redis NuGet 插件 — Redis 版 IIdempotencyStore + IDistributedRateLimitStore，AddSharkableRedis()

功能原因
CQRS-lite (ICommand/IQuery)需重写每个端点类
模块化 ISharkModule需大面积重构
强类型 ID (OrderId, UserId)需改所有方法签名
智能枚举需改所有枚举定义
缓存标签失效需改写入端点
API 测试运行器需写新测试代码
轻量网关需建新项目
Source Generator SDK需新包 + 客户端代码
